# Create a GIF with Python

This project creates an animated GIF from three PNG images using the `imageio` library.

## Files

- `create_gif.py` — reads the images and creates the GIF.
- `images/` — the three source frames.
- `output/my_gif.gif` — the generated animated GIF.

## Run the project

```powershell
py -m pip install -r requirements.txt
py create_gif.py
```

The finished GIF is saved as `output/my_gif.gif`.
